# 首份角色聊天演示的决策地图

Labels: wayfinder:map
Status: open

## Destination

明确制作、展示并评判首份五情景角色聊天原型所需的素材、依据与实现边界，让用户能判断人物感、生活连续性和交流自然度。目的地是可验证的体验路线与原型反馈，不是宣布完整角色生活系统已实现。

## Notes

- 用户已经确认的需求只存于[角色聊天方向记录](../../docs/plans/character-chat-direction.md)的C1–C18；这里不重抄，不把研究建议升级成用户决定。
- 快速阅读可看[首份演示体验蓝图](spec.md)；实际原型工作开始前仍按AGENTS落实唯一任务书，本地图不授权并行实施多个功能。
- 使用Wayfinder、grilling、domain-modeling；技术研究使用research，原型票使用prototype。没有独立Skill调用工具时读取相应SKILL.md执行。
- 本地Markdown tracker：每张票单独文件；Status为open/claimed/resolved，Assignee为认领者，Blocked by引用同目录票号。只有依赖全部resolved且未认领的open票可取，按编号排序。
- 地图只作索引，票据正文提出问题，答案在各票Answer部分；不将实现待办假装成决策。HITL结果只能由用户反馈解决。
- 该小范围地图、票据与研究结论纳入Git；不放小说原文、凭据、私人文件或运行数据。其余.scratch仍保持忽略。
- 当前无新的Provider用途或素材外发批准。研究只用公开官方资料；原型的预设台词、模拟时间及真实能力明确区分。

## Decisions so far

- [小说提取如何保留来源与起点边界](issues/01-novel-source-boundary.md)：复用阅读顺序与位置证据，独立核对剧情时间/人物知情；未选定依赖。地图建立前的用户体验决定仍见方向记录。

## Not yet specified

- 小说证据不足或存在歧义时，人物设定确认页如何表达不确定性。
- 五情景需要哪些最少的日常状态才能连贯，而不提前设计整套世界模拟。
- 原型反馈会暴露哪些人物语气、关系分寸和生活节奏缺口。

## Out of scope

- 当前地图不实现完整视频理解、常驻生活模拟、生产通知服务或旧身份迁移；它们仍属于总体愿景或后续专项。
- 不把本地图当作整本小说发送到模型的授权；相关用途、内容及目的地需另有具体方案。
- 原创角色双入口已经是确认需求，本次五情景以小说版和泉纱雾为参照，不同时制作第二套角色演示。
