# v1候选版使用指南

版本：dogfood-s51。当前主线是日常对话、持续记忆与目标、明确文字任务，以及确认后保存本地文本。

## 打开与选择身份

双击仓库中的`启动Avery.bat`。已有DeepSeek连接可继续使用；首次使用在“连接设置”中保存并验证自己的key，界面不回显key。

旧身份继续按原权限聊天，历史没有被升级或清洗。若任务面板显示尚未启用，可通过“来源建角”创建新身份：输入有权使用的原创纯文本，逐次确认提取用途，选择候选并保存草稿，预览设定后明确封存，再切换到新身份。新身份有独立经历，不继承旧角色的记忆和关系；不要把它当同一角色的历史升级。

## 对话与记录

可以直接说“我叫小澄”“我的目标是写完展台卡片”，再问“列出我的目标和承诺”。目标清单最多显示5条；右侧面板可核对当前记录。对封存资料的问题，会给出来源引用；未知内容不应被当成资料事实。

“请忘记我的名字”会停止活跃使用相关记录，之后不再向模型提供该记录；旧聊天和本地审计原文仍保留，这不是物理删除。

## 从文字到成品

1. 在聊天中创作或自行准备正文，例如“请写两句陶艺桌邀请文案”。选择自己要保存的文本。
2. 打开“主体任务”，选择“文本保存”，填写任务说明并贴入正文。说明和少量未结束任务摘要用于模型协商，正文保留在本机。
3. 提交后查看接受、需要补充、暂缓、未接受或失败状态。任务接受不等于已经生成或保存文件。
4. 已接受且有正文的任务可点击“预览保存”。核对完整正文和准确路径，再点击“确认保存这份完整正文”。返回不会保存。
5. 看到“已保存”后，从任务卡复制完整路径到文件资源管理器地址栏打开文本。只会新建文件，不覆盖已有文件；保存不调用模型。

修改正文后需要新的预览与确认，旧确认失效。文件名固定，不会因冲突偷偷另存一份。起草任务不自动后台写作；可先在聊天完成创作，再把选定正文补充到任务中。

## 中断与失败

已批准保存若被程序中断，重开后可以点击“核对已批准的保存”；下一次提交也会先核对。重复同一确认不会重复写文件。未批准的预览和草稿不会自动保存。

遇到保存失败，原有文件不会被覆盖或删除；可核对目录权限，重新交付任务并再次预览。界面关闭后不保证程序继续运行。已完成记录说明当时保存成功，不监控你之后在外部修改、移动或删除文件。

## 当前限制

这是可体验的v1候选版，尚需本人持续使用反馈。复杂自然措辞仍可能需要澄清，生成修改可能失败；个别无关轮次可能出现目标子能力失败说明，独立聊天与已有目标保持。知识回答偶有冗余前言，以完整引用及当轮说明核对。

不支持定时提醒、主动消息、任意工具、邮件发送或自动人格发展。旧身份使用新任务/保存能力需要另行确定升级方案；当前不会自动迁移。
