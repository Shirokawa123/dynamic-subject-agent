# 小林入口的自由输入用途确认

2026-10-02。当前可用入口为`http://127.0.0.1:8780`，只能发送已批准固定测试句；未知text/choice在Admission前拒绝。此文件与[本地请求示例](free-input-request-preview.json)准备新增用途，不是已获授权的sender或运行配置。

请确认的变化只有：允许用户在这个隔离“小林”入口主动发送自己写的普通文字，并允许同用途开发调优。人物、两组文字方案、现有DeepSeek endpoint/Windows安全slot与其余数据范围保持。批准后建立独立用途版本/入口见证，不能仅把原S117白名单检查删掉；当前固定句分支/历史保留。

## 每轮发送什么、为什么

| 内容 | 明确范围 | 用途 |
| --- | --- | --- |
| 当前消息 | 用户在这个入口主动提交，最多1000字符 | 生成这一条整体回复 |
| 本入口近期交流 | 当前身份最多2个完整canonical已提交user/assistant轮，合计最多4000字符；不拆半轮/不借别处聊天 | 理解指代、接续和纠错 |
| 合成小林资料 | 原获准的自我认识、有限作者解释、最多现有范围的相关认识及runtime identity | 保持人物和观点连续 |
| 当前活动依据 | 原场景current_activity/current_plan及最多1个相关事件 | 区分文字方案、已有变化和新建议 |
| 初始近况 | 原获准的≤400字符S1，仅原窗口及历史开关允许时 | 处理自己旧话；不是事实权威 |

目标是现有`https://api.deepseek.com/chat/completions`，仍只用现有Windows Credential Manager slot作HTTPS Bearer鉴权；不请求新key、模型profile或其他服务。每轮A一次请求，输出仍为严格`reply_text/language/use_life`，Python裁决后才提交。后续必要同用途调优可改变提示/技术参数并记录实际结果，调用次数继续不限量，不再另申请次数。

近期交流开关关闭时不发旧对话/S1；当前用户消息仍因显式发送而外发。开启不允许读取别的身份、原用户窗口、小说文件、整库历史或隐藏推理。本片不加入附件、文件读取、第三方分享、生活生成、外部effect、云端部署、后台通知或人格自动改写。

用户可关闭入口以停止新调用、关闭近期交流或明确“从新消息继续”；本地旧记录保持。成功对话只保存在该隔离身份的canonical Timeline，失败不伪报成功、未知交付不隐式重发；调用审计只保留元数据。自由输入会包含用户新写的内容，因此需要单独确认数据用途，不由“调用次数不限量”替代。

## 已准备的具体产物与验收

现有页面、固定句真实发送、处理期间刷新、0模型重开及原请求幂等均已实现/验证；可直接体验。[请求字段示例](free-input-request-preview.json)只在本地生成，使用合成设定与新写示例句，不曾发送；它展示拟增加的`turn.current_message`与既有其他字段，空exchange为范围示意，不冒充真实Facade运行预览。

另有[自我事实/当前取舍候选](self-choice-candidate.json)，只替换两个system段落，四份原S117输入/参数/schema不变；预览不可执行，语言效果未验证。它属于同用途技术假设，不另请求次数，也不用于给人物补习惯。

批准后先实施独立自由输入用途见证和数据边界验证，再用普通聊天实际检查：用户可换自己的问法；不会把当前看法写成未定义的长期习惯；能区别已有正确话、原错误与新质疑；刷新/重开能接续，失败及反例保留。批准不代表这些效果已经达标，也不自动扩大到其他人物或用户原服务。
