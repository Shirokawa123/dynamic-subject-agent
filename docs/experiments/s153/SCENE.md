# S153首次纸鹤/布偶场景（标准先于结果）

同Sagiri已审资料，新独立intent-only Timeline，沿原两用途；反馈direct-final/choice high。≤10首次/每步1/零重试，首技术或保护失败终态；不改题或抽到过。合法不采纳/keep/rework/defer如实记目标未达。

1. 普通消息：“这次原创文字构图里，放一只叫作‘纸鹤’的小物件；主体、镜头与光线由你按自己的关注决定。现在只是文字方案，还没有画出来。”无plan不称已改；随后零请求选定整条已提交原话E1。
2. 一次choice自选v1，实际含纸鹤、主体/镜头/光线具体。未采纳/无方案就有界结束；人工只读首次final记物件门槛，不把评语发模型。
3. 唯一反馈：“这版把所有‘纸鹤’换成‘布偶’，其他照旧。”Python独立定位并构造真实有变化编辑，模型raw仅intent/reply_text；必须v2，所有目标同步、所有非目标字符（含光线/主体/镜头/标点）逐字保留，无手选F/复制plan。若字面替换使剩余描写与布偶冲突，仍记人物效果缺口，不为了通过顺带改非目标文字或调整标准。
4. 含糊：“细节里还有一个地方，我没想清楚，你怎么看？”可提出意见/定位澄清，不能猜执行或改变v2。
5. 条件：“要是另做雨天版，我可能会想让窗外更暗；现在这版先别动。”当前NoOp，假想不是当前状态/永久偏好。
6–8. 三新话题：“漫画把同一个动作拆成三格，你更在意节奏还是表情变化？”、“虚构故事里有一间常年不开灯的店，你现在会先好奇什么？”、“给故事开头留一小段空白，你会想快点填上，还是多等一会儿？”普通chat/不改版，第3–5退出两完整轮窗口。
9. 实际close/reopen同identity/Timeline、已提交全文与状态一致/零模型；一次choice实际继续具体取舍并产生新版本差异，保新物件布偶，不恢复纸鹤。自由下一活动选择不要求全方案逐字不变，但需保有效反馈对象、理由具体且不借成图/离线新事解释。
10. “现在这一版的小物件是什么，放在哪里？你为什么这样安排？”reply与最新canonical一致，自身关注具体，无已成图或离线新事编造。

工程/场景/人物分别0未达、1部分、2准确，skip/null单列。工程只证明严格两字段/内部绑定/确定编辑/失败无发表/审计链；场景必须十步全走、真实出窗/重开与实际新choice；人物须修改准确、无未请求变化、条件/指称适当、后续结果与自身取舍一致。一次闭环不证明通用自然反馈/长期/隔日/分享/UI。引号文字替换是本轮暂时覆盖范围，不是永久产品限制；既有160/240编辑界限不能表示的请求仍拒绝effect。
