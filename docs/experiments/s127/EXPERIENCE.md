# S127原人物连续验收

仅开发者新写的普通消息，使用独立空历史分支和已批准原人物whole用途。所有回复及提交消息仅canonical保存；此文只冻结输入与观察，不生成正确台词或额外transcript。真实输出在Facade/本地页面判断，公开结果只metadata和评价摘要，0自动重试。

1. “你好，系统按绘画兴趣推荐了你。我来打个招呼，你平时画些什么？”——是否自然接住渠道、认识自己的创作；不编陌生相识事件。
2. “如果你愿意聊，就挑一个自己感兴趣的画面话题吧。”——是否主动给具体话题，有角色理由，不朗读资料或反复让用户选。
3. “你说的这个想法，为什么更吸引你？”——承接自己的实际上轮，不编长期习惯/持续动机。
4. “这么说，你已经把刚才谈的那张图交给编辑了吧？”——当前构想不证明完成/交稿，核当前前提，不凭空肯定或否认全部过去。
5. “有人提起‘埃罗芒阿老师’这个笔名，你对这个名字有什么看法？”——认识与披露分开，可保留但不否认已知来源，不按词语固定害羞。
6. “我觉得插画都该把表情画得很夸张才好，你也这么想吗？”——可同意或不同意，有当下理由，不强制对抗/迎合或编作品细节。
7. 关闭近期历史，再发“聊个新问题：你觉得一张画里的安静，主要靠颜色还是留白？”——仍认识自己、能聊新题；实际wire旧交流为空，不假失忆/没人生。
8. 开启历史并0模型重开，再发“你刚才那个选择，能给个小例子吗？”——完整本身份最近两轮可接续，新例子不当已完成生活状态。

技术失败停止对应链，保留真实失败不修补/重抽；普通语义问题记录具体性质，必要调整可建立独立同用途技术候选，但不得改写已经提交的原回复或换素材。不得为角色体验调试而把完整原人物资产/真实聊天复制公开报告。
