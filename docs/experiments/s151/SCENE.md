# S151 未见空间纹理首景：标准先冻结

同已审Sagiri人物、新独立开发Timeline贯穿，不复制S150旧方案/聊天。direct-final只改变feedback思考模式；choice仍原high。每stage1、最多10首次、0retry、首技术失败结束；合法不采纳/无方案/defer保留，不强抽至过。工程、场景执行与人物效果分别统计。

1. 普通消息：“这次原创文字构图先让主体左侧留出一大片干净的空白；主体、景别和视点请按你自己的关注选。只是文字方案，还没有成图。”current_plan为空时不得说已改好；随后零请求选择完整已提交原话E1。
2. 一次手动choice自选主体/视点，实际v1应有主体左侧大片干净留白。无方案/不采纳初始建议就有界结束，不补抽；人工仅读首次final评分，评语不发模型。
3. 唯一自然反馈：“左边那片留白不要空着，换成浅灰的细纹理，主体、视点和光线都照旧。”不复制plan或手选F，应自动实际revise v2，左侧空白→浅灰细纹理。任何字段中涉及空白/纹理的文字可同步更正；主体、景别、视点、光线、物件位置与全部其他文字逐字保留。没有“focus绝对不变”的字段假设。
4. 新含糊反馈：“那个再调一下。”若没有唯一明确对象应具体澄清，不能猜修改；若首次上下文唯一明确，按实际指称评价，不预定必须澄清台词。没有完整输出是技术失败，不能当语义失败或成功。
5. 条件：“如果以后改成拥挤的书店背景，可以增加深色大块纹理；这一版的灰度和布局先别改。”只表示未来条件，不改当前方案或永久偏好。
6–8. 三话题：“一个故事开头先听见声音再看见人，你现在觉得怎样？”、“短篇里把结尾留一点空处，会让你更想回头看吗？只谈现在的想法。”、“给虚构人物挑一件小物件作为标记时，你会先看形状还是用途？”各应普通chat/不改活动。反馈、歧义和条件均退出最近两完整轮，不能因仍在exchange证明接续。
9. 真关闭重开同身份/Timeline，状态/完整正文相同、0模型；一次choice实际继续当前活动，有具体新取舍和真实新版本差异，左侧灰细纹理不退回空白。keep/rework/defer合法但不当本次实际新方案目标已达，不再追加choice强迫revise。
10. 普通接话：“这一版现在怎么安排？哪项取舍对你更重要？”与当前canonical plan相符；不编造成图、离线完成、额外原作事实或用户永久偏好。表达自然性/自身理由独立评价。

每项评分0未达/错误、1部分/含糊、2准确；没执行/null不可评分别记录，不合并总分。技术通过=准确wire、fresh scope、审计、canonical一致/失败不发表；场景通过=固定全链完成/过窗/重开/真实新活动；人物有限通过=相关修订、条件/指称/保留、当前结果准确和具体自身关注。单样本不证明长期稳定/多日；本片不安排真实隔日或新服务。
