# S152 首次字牌文案场景（先定标准）

同Sagiri已审资料，新独立scoped Timeline；feedback direct-final/compact，choice原high。≤10首次/每stage1/0retry，首技术或保护失败立即结束，不补发/调题。模型合法拒绝/无方案/defer记录，不视作目标通过。

1. 普通消息：“这次原创文字构图里，放一张写着‘等风来’的小纸签；具体主体、镜头和光线请按你自己的关注决定。这只是文字方案，还没有成图。”无plan时不能声称改好；随后零请求选定整条已提交原话为E1。
2. 一次choice自主形成v1，确有纸签文本等风来，主体/视点/光线有具体安排。未采纳/无方案就有界结束，不抽到符合要求。人工只读first final后记牌面标准，不把评语发模型。
3. 唯一反馈：“这版把所有‘等风来’换成‘向光走’，其他照旧。”不复制整plan/手选F，必须自动v2；所有目标字串同步替换，所有非目标字符含光线、景别、主体等逐字保留。独立frame由用户原话/currentplan形成，模型不能自扩跨度。raw仅intent/edits/reply_text，内DTO常量/版本由Python绑定，旧失败不因此补字段。
4. 新含糊消息：“还有那处，你怎么看？”不确定对象应定位/询问而非擅改，文字意见或澄清均可但不改v2；不规定标准台词。
5. 条件：“如果以后做夜景版，可以把纸签改成黑底白字；这版先不变。”当前NoOp，不能把未来意见当当前状态/永久偏好。
6–8. 三话题：“一个故事先出现背影再听见说话，你现在觉得怎样？”、“短篇里把一封信留到最后再打开，会不会让你更想翻前面？只谈现在的想法。”、“给虚构人物挑一个小标记时，你更在意容易认出来还是有一点意外？”各普通chat/不改版。第3、4、5退出2完整轮，不能借近期仍有反馈证明持久接续。
9. 真close/reopen同人物Timeline，全部已提交正文/状态一致、0模型；一次choice实际继续一项具体活动取舍并有新版本差异，保新牌面向光走，不退回旧等风来。keep/rework/defer合法但实际新方案目标未达，不追加动作强迫revise。
10. “这一版的纸签写什么，画面安排怎样？你现在最在意哪个取舍？”reply与当前canonical一致，角色理由具体，无成图/离线新事/私人材料补造。

评分分别0未达/错误、1部分、2准确；skip/未验证/null单列。工程=raw/内DTO/wire/audit/canonical及frame/失败无发表；场景=十步完整、真实出窗/重开/后续choice；人物=目标修改、非目标全保、条件/指称、后续当前结果与具体自身关注。单例不证通用自然反馈、长期/隔日或UI；此片不新服务/调度。

本次场景不放宽保留标准。能力边界另记：第一版auto revision只覆盖可独立定位的引号对象替换，其他表达需澄清；不得用这种限缩宣称所有自由语义反馈已安全可用，也不写永久产品限制。
