## 现有能力与已核旧坑

复用S105 monotonic/15秒短session lease/单窗口owner/busy与助手-origin消息，S139–141方案/源依赖/完整prepared/Publication。新scope独立schema6，单canonical store，无另一个scheduler/outbox状态库。Authority registry只持资格、开关、permission revision等权限权威；Timeline快照不成为第二份控制权威。

旧FirstLifeClock实际阈值60秒，S142工作假设900秒；短租不足/失联清累计，离线不补，时间只给提议机会不证明完成。旧initial_life_record默认暂停false/分享true，新资格必须暂停true/分享false。旧FirstLife对kept/deferred硬停不可搬，shared已允许其后续revise/defer。分享eligibility仅实际start/revise新文字版本，不将keep/defer/rework事件当可分享新内容。

true/false皆canonical考虑一次，false不发送/不设未回；无新eligible结果、控制关、已考虑、未回或日满在模型前0请求。新话题上限是UTC8已提交true分享≤2，不是旧false也消耗的分享budget2。旧日6/2/200和开发子限全部保留历史，不升级为新用途授权或新模型限额。

旧Timeline._share_day_expired对SHARED_INTENT直接false，新typed share必须接日/权限/完整head最终与coldprepared fence。跨日/关闭后重开不得复活旧候选；旧receipt次日仍可只读。模型/网络失败不是角色创作失败，更不产生图画/外部事件；明确needs-attention停新自动动作，不能偷偷重试。

answered只说明后续有成功普通交流，不能判断讨论过分享，也不能作两轮授权窗口。新reply从share frozen head之后数完整成功user轮<2；失败/GET/重启/控制/跨日不耗窗，首成功解除未回后第二追问仍可带同share。分享本身不是user/assistant完整轮，不能伪user_text混入两轮库存。

所有supplied内容产生依赖，不能信模型声称未用E1。计划/结果/分享/获得它们的完整旧回复需携本地source+传递dialogue lineage；停用/换源（含同head片段替换）/history-off/cutoff整项过滤，包括选定前回显。before/diff/decision_note不外发。已知普通expression失败只截近期窗，不替代用户撤回E1；未知/损坏/权限不明继续failedclosed。
