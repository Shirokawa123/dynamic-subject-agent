# 持续生活和主动分享的下一步草案

这是S141准备中的助手方案，不是新增授权或已经运行的能力。先以S141实际自主出发点/版本承接评估适用性；若仍只等用户或不能连续交付，不能把定时器当人物生活改善。角色离线生活和有分寸的主动联系目标保留。

## 建议先走的具体增量

新独立分支沿同已审人物；首期应用开启时，由本地累计在线15分钟提供一个活动决策机会，默认暂停，可关闭或调整。计时只是决定何时考虑下一步，不声称15分钟里已经画完什么；关闭后不补算，离线补算是下一独立机制。只有既有活动有待处理/比较处时才调模型，每机会最多一次、0自动重试，失败自动停止新自动动作并显示需要检查，不自动补抽。当前手动按钮继续可用。

每日最多两条新话题的产品上限沿C15，不是必发或模型额度。只有新提交且可分享的活动结果才考虑一次应用内分享，可不分享；未回复时不继续开新话题、不催促、无变化0请求。分享和生活暂停独立控制，系统通知关闭，首期只应用内。

活动自动触发拟复用S139同background/E1-or-null/current_activity/current_plan字段、同HTTPS/Windows slot；新的**自动触发用途**需明确批准。实际时间、内部ID、草稿、未提交文本、未选历史和新心理画像不出站。单writer、原子Publication、source停用及控制改变后的prepared取消、跨重启原nonce不重生成仍是验收门槛。

分享拟为新ModelTask：background、当前有效的一条E1-or-null、最多一个已提交文字活动结果及其有限action/plan，不读额外对话；output为share布尔、自然中文message≤400和language，false时正文空。本地检查存在合资格新结果、来源仍有效、分享开关、未回复/日限/同结果不重复后才提交应用内助手消息，不伪造用户轮。新purpose/字段和精确policies/wire须freeze后集中审阅；此草案没有可执行grant。

普通后续聊天如何引用刚分享的原话仍需准确定义（例如最新一条≤400字符已提交主动分享仅两次普通接话且history可关闭），不能凭借旧S108或已有shared reply批准直接启用。新分支初期不迁移旧8790记录；若要接续用户已有长期分支，先准备可逆版本升级/历史保持的具体方案并核授权，而不是强迫用户每次永远重建人物。

## 准备完成后集中审的内容

精确材料binding、最小投影、触发时钟/暂停恢复、输出schema及policy SHA、一次票据/双用途audit、SOURCE依赖过滤、逐步可运行LOCAL情景、真实首轮场景与失败结束条件。先做无远程可执行资格的本地准备，再请求准确自动活动/分享用途批准；不要求用户现在选技术参数或逐步骤确认。
