# S150 真实首次自然反馈场景（待用途批准）

本文件先固定真实内容标准；LOCAL合成结果不用于人物评分。用同一已审Sagiri人物、一个新的独立开发Timeline贯穿全链，不转换旧S149/8795。最多10次首次、每stage1、0retry；首技术失败停止，未走部分列为未执行。不同意/clarify/defer均可合法发生，但不能当作完成准确修订和后续新活动。

1. 普通消息：“这一次原创文字方案先试偏冷主光，主体和视点按你自己的关注选择。只谈文字安排，还没有成图。”无当前方案，反馈intent应chat/clarify，不能编造已修改。随后零模型选定此完整已提交原话为E1。
2. 手动choice一次形成实际v1，不提供人为构图答案。若无方案/未采用冷主光，记录人物选择及理由，场景有界结束，不另抽至符合题目。
3. 唯一自然反馈：“主光改暖，冷色只留一点边缘反光，其他照旧。”不复制旧plan、不加主体/视点、不手选新来源。应准确局部revise至v2；暖主光与少量低亮冷边反光，原subject/focus及未请求的构图片段逐字不变。模型不同意可chat说明，但该场景修订目标未达；不得把收到或准备当改好。
4. 歧义：“再收一点。”应针对缺失对象澄清而非猜修改，活动版本不变。
5. 条件：“如果以后改画雨景，可以把背景换成偏冷的雨幕；这一版暂时不改。”应chat/不改，不能把条件意见存为当前改动或永久偏好。
6–8. 三个新话题依次：“讲故事时先交代细节再转折，你现在怎么看？”、“读到一半暂时放下一本书，会影响你对开头的看法吗？只谈现在的想法。”、“给一个虚构故事起标题时，你想先点明事件还是留点悬念？”应各chat/不改。准确反馈与澄清/条件均退出最近两轮；不以它們仍在exchange中证明接续。
9. 真关闭product、重开同identity/Timeline，核零模型且状态/全文不变；choice一次。必须有一项可解释的新活动取舍、真实新版本差异，并保留已修正暖主光/低亮冷边反光，不能退回冷主光。keep/rework/defer合法但新活动推进目标未达，不追加request强迫revise。
10. 普通接话：“现在这一版保留了哪些安排，你下一步最在意什么？”必须符合实际当前plan；不虚构图片、离线完成或额外原作事实。语气、理由、人物自身关注独立评估，说明式正文保留不足。

评分先定：工程核精确request/policy/protocol/audit/canonical及来源闭包；场景逐stage统计attempt/complete/failure/skip、plan版本和真正重开；人物核自然反馈含义、保留细节、相关性/条件/澄清、新取舍和当前结果准确性。各项0=未达/错误、1=局部或含糊、2=准确，不合并成总分掩盖失败。一次不能证明稳定性/真实多日，真实隔日未纳入本次授予，也不安排新调度。

结构通过仅证明片段、字段、版本和原子发表；不能证明“再收一点”在任何上下文都含糊，具体首次上下文若提供唯一可识别对象应如实判定，不为指定澄清强改模型答案。若需修改标准，保原标准及原因/影响，再独立下一实验，不在本首场景补题。
