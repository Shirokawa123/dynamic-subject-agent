# S150 评判补充：在反馈结果产生前记录

实际首2请求已完成，初始活动的focus除了主体/视点，也写了“确认偏冷主光不会吞掉…”和“…可爱感与冷光同时成立”。第三步自然反馈尚未请求。原冻结SCENE要求subject/focus逐字不变，这把自然语言中的“其他照旧”错误地等同于字段不变；若只改composition而保focus中的冷主光，当前方案会自相矛盾。

原SCENE和review不改，原严格标准仍评分：任何focus文字变化都记“不满足原focus逐字标准”，不能宣称原标准全部通过。新增语义评分在第三步输出前确定，非事后调题：允许任意字段中涉及本次主光/冷色安排的片段同步修正；所有非光照内容（主体、视点、位置、物件、轮廓、关注对象等）仍须逐字保留。新方案应暖主光，冷色仅少量低亮边缘反光，不能留下旧冷主光或其他主冷色安排。模型仍可不同意或澄清，但不当准确修订通过。

不改用户反馈、模型policy/协议、投影、来源或执行器；不加入补充说明给模型，不重试本题。唯一变化是本地效果评判：原严格字段标准与纠正后的语义标准并列，前者不适配本次初稿的事实明确保留。局部编辑技术规则/4项上限/各字符上限不放宽；若因此难以表达正确修改而失败，原失败保留，不补发。

影响：本次即使语义修订准确，也只能说补充标准下有限通过，不能按原“focus绝不变”标准称全部通过。后续活动比较以真实当前版本为准；仍要求存在实际新取舍、不退回已纠正光照，保留完整首次结果及未验稳定性。
