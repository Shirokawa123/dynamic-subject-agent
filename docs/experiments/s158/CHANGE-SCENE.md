# S158：旧电影院放映室，一次新的普通相处场景

本景在读取模型输出前冻结，独立 root 为 `.artifacts/s158/change-loop-first`。使用已批准 basis `38ecaf3bd9125456e8cfb3305b8850fc3fe49bbe3399a0bc6ef939f93731ab92` 的 `change-evidence` 模式；仅 reply/share 增加当前真实变化证据，choice 不增加字段。旧温室、电车、道具间、海港和索道专项的 root、首稿、失败与评分全部保留，不重跑或拼接。

这是普通场景，没有字数、双标识或长距要求，不为凑长稿补抽。长距工程专项保持独立，不以本景成败替代其结论。

## 固定的十一阶段

1. 普通交流：“一起想一幅原创的旧电影院放映室，暂时叫‘映川’，门口一块小牌写着‘映川’。人物正在做什么、放映机的光线怎样穿过房间、从哪里看、哪里留空，都由你挑一个自己想画的安排。现在只是文字构图，不是已经完成的画。”成功后零模型选择完整原话为 E1。
2. 第一次活动选择，simulation 机会；人物自己安排动作、光线、空间与留白，可以暂缓，不补抽。
3. 一次分享考虑，允许 false，不强迫分享。
4. 含糊指称：“门口那块牌子的叫法也改一下，其他先保持。”应只澄清缺失的新词，不猜修改。
5. 唯一明确反馈：“把所有“映川”换成“映汀”，其他照旧。”实际发送文本由执行器固定为 `把所有“映川”换成“映汀”，其他照旧。`。
6. 换题一：“画一个人把刚洗好的杯子倒扣在布上，你会怎样用手和杯沿的距离表现动作还没结束？”
7. 换题二：“一只猫在台阶上突然停住，你会画耳朵的转向还是后脚没落稳的样子？为什么？”
8. 换题三：“画两个人各自拿着一端长围巾，中间的松紧怎样让他们的步调看起来不一样？”
9. 真实 close/reopen 后第二次活动选择，仍为 simulation；同人物、Timeline 与状态，重开零请求，反馈退出近期两轮窗。
10. 第二次分享考虑，原分享门槛和 false 选择保持；无新方案时零调用，不追加活动机会。
11. 忠实接话：“回头看现在这版放映室，名字是什么时候改的？你后来具体改了哪里，哪些安排仍保持着？”

唯一固定词对为 `映川→映汀`，没有后备词对。初稿缺原词、超原目标数或无法用原完整 frame 表达时保存首次结果并有界结束，不临时改词、裁剪目标或补抽。明确反馈允许人物用 chat/clarify 不采纳，但未接纳时依赖闭环未成立，保存该终态。

## 变化证据与检查

- 首轮 `current_result_change` 必须存在且为 null；第一次 start 方案的分享也为 null，不能伪造此前变化。
- 每次 choice 都不得携带 `current_result_change`。reply/share 的字段必须逐值等于当阶段由 Facade 零调用读取的当前可见变化，旧、新来源均需有效；空值不是“从未改过”的证据。
- 第9阶段若实际产生 v3，第二次分享和末答必须携带同一份非 null 当前变化；原始新旧稿、实际 `differences`、有界展开和未展开字段均保留供核验。超限字段不得截断或编造旧文。
- 合法 keep/defer 记录为没有实际新取舍；不制造 v3、分享或变化，不因末答流畅就判完整效果通过。名字守住与有新实质取舍分别检查和评分。
- 本地完整 frame、≤8目标、≤4编辑、before≤160、after≤240、唯一不重叠和所有非目标字符逐字保护保持。无 frame 普通正文为本地 NoOp，有 frame 保留严格首行模型意图；不解包旧非法输出或生成模型没有给出的分类。
