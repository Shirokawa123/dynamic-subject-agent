# S140 本轮开发与真实验收范围

本片复用2026-10-03准确S139用途及同用途技术调整授权。已批准数据边界、材料、Provider、Windows slot和每动作一次请求/0自动重试不变；不需要重新批准相同用途。新增UI与Facade原nonce只读查询没有模型调用。新自然表达候选使用明确版本/独立新root和准确policy preview，原baseline pin与旧root不修改或迁移。

[场景](scenarios.json)是本轮合成验收消息，不代表用户个人事实。3支最多18请求；一个完整成功分支再3个新消息观察范围澄清、换题及停用后的连续性；同输入baseline/候选各2消息，最多4请求，总最多25。这是有界实验的结束条件，不恢复旧模型额度或设新永久次数限制。每支首失败停，不重建旧失败分支补抽，UNKNOWN/原文不一致终止相关工作；其他独立首次链可继续。

观察经真正用户HTTP入口执行，而不是直接伪造页面或填充助手文本。页面状态、刷新、原请求查询、同nonce重取与重启不触发模型。模型表达与方案正文只canonical，报告存请求/协议/正文摘要、状态、用量与本地语义判断，不另存真实prompt/私聊全文/隐藏推理。技术通过与人物结果分开。对照无法排除模型随机性，不以单次结果证明稳定因果；空白原始正文缺失时记录边界事实并停止本支，不无限追查服务内部。

正式新入口空历史，不预灌开发台词。验收使用独立开发root/端口，旧8788及其记录、用户草稿保持。不开启后台生活/通知、自动人格重写、Reflection、云或迁移；后续持续生活/分享另准备具体触发与准确出站方案。
