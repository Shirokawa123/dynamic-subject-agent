## 目的

dynamic-subject-agent继续作为能脱离梅莫莉使用的独立角色产品发展。用户可以长期认识同一个来自作品或原创设定的虚拟人物：她知道自己是谁，有自己的关注、目标和生活，相处过的事情会影响此后的理解、选择和行动。

成长与改变、坚持与拒绝都可以体现主体性，具体取决于角色及其经历。人物不会统一趋向顺从、开放或亲近用户；也不以随机反对表现个性。不以机器具有意识或人类情感为产品前提。

## 核心功能与关系

| 功能 | 用户应能观察到的结果 |
| --- | --- |
| 有依据地创建角色 | 从作品或原创设定形成可核对的人物、起点与知情范围，能够纠正提取错误 |
| 持续交流与记忆 | 换题、重开、再次见面仍是同一个人，能准确接续重要经历和未完话题 |
| 共同经历与关系 | 说过、误解、澄清、一起做过的事情，实际影响对用户的认识及后续选择 |
| 状态、目标与自己的生活 | 当前处境影响回应；自身目标让活动具有持续方向，活动结果影响下一步 |
| 有分寸的主动表达 | 有值得分享的事或想继续的话题时主动表达，联系频率和暂停由用户控制 |
| 有来由的成长与坚持 | 某些稳定偏好和看法可以逐渐改变，也可以因经历而坚持或拒绝；变化符合具体人物 |

人格提供相对稳定的倾向，记忆保留经历，共同经历影响关系和判断，状态反映当前处境，长期目标连接活动，主动性体现为角色自行选择行动与表达。上述是体验要求，具体机制按实际缺口确定。

主要方向允许自然成长并可选查看变化来由，同时保留仅通过相处发现和影响变化的方向；解释入口不是所有角色或产品形态的必备项。

此前确认的可选故事起点/世界模式、原创设定导入与问答辅助、默认短消息、初识关系、可暂停生活及有分寸联系仍作为长期方向保留；细节和适用阶段查[历史决定C1–C20](plans/character-chat-direction.history-2026-10-29.md#已确认的决定)，不作为本阶段待实现清单。

## 验收与现有边界

每阶段围绕一个完整、可观察的结果。人物依据、经历和状态应在具体互动中改变行为；工程测试通过与人物体验通过分别说明。达到本次验收即交付，新的失败或明确疑点再扩大检查。

保留身份隔离、单一时间线、原子提交与恢复、模型提议/程序裁决和最小授权数据用途。用户记忆、角色经历、原作事实与真实聊天各有来源。成长目标不直接启用自动人格重写；新模型用途、后台运行或迁移仍按具体合同落实。
