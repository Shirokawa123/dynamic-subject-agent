# 产品定义

## 一句话目标

构建一个本地优先、具有持续身份的主体型陪伴 Agent：它从封存设定和授权知识起步，在同一条时间线上经历、记忆、修订、形成关系与主体状态，并能在权限内协商、拒绝和执行低风险行为。

## 用户体验

1. 用户创建或选择一个有来源的原创身份，并明确运行与数据政策。
2. 每天打开仍是同一主体；身份、记忆、关系和状态跨进程恢复，有日期锚点的计划按当天重新表达，封存身份持续约束回复，并能按自己的 committed Timeline 回答上次互动日期。
3. 角色只使用封存知识，未知时不编造，引用可见。
4. 用户陈述先成为候选；只有证据和 Python 规则通过后才形成 Memory、Belief 或状态。
5. 状态按 Situated、Medium、长期倾向分层，不能由一句台词直接永久改写。
6. 用户请求只是 Agency 的候选；主体可以接受、协商、延迟或拒绝。
7. 关系由 Subject Stance、Interaction Norms、Mutual Commitment 和 Relationship Narrative 表达，不使用总好感度。
8. 外部 effect 必须先提交意图与授权，再幂等执行；用户始终控制导出、备份和删除。

## v1 完成条件

- 本地 serving；
- Knowledge + Memory runtime retrieval；
- 真实 Memory；
- 目标、承诺与 Agency；
- Relationship；
- Situated 与 Medium State；
- 一个安全本地 committed effect；
- Windows 图形界面、重启恢复和真实用户持续验收。

## 非目标

不声称意识，不模拟用户，不以随机唱反调表演主体性，不让模型写数据库，不做多 Agent 委员会。人格发展、Reflection、Lifeworld、主动消息、多人物社会与长期情绪诊断在单独产品决定前保持冻结。
