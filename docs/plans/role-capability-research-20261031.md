# 从内容实例的问题回到通用角色能力

2026-10-31用户明确：梅莫莉是dynamic衍生的内容实例；效果问题应推动底座能力改进，主动查找、学习和借鉴论文及其他项目。此决定调整当前研发重心，梅莫莉的完整互动目标保留。

## 已核本仓缺口

- `EvidenceExtractionLab`能通过ModelGateway提出带逐字引用的证据候选，但当前仍绑定三包样例实验；不是通用的材料到角色理解流程。
- `CharacterEvidenceModel`校验并组织已有草稿及来源，`CharacterPersonalityLab`读取外部写好的解释，再用于交流规划和表达。不能把加载人格文件算作系统已经从材料形成解释。
- 当前梅莫莉使用预先整理的人物认识/作者解释。Codex在对话外读原作、手写风格提示不能作为底座能力交付。
- 目标/承诺旧模块主要记录参与者原话；工作理解、有限生活与整体接续有特定活动范围。需要核实际接口和用途，不能把它们直接当作已接通的角色自身长期目标与当前关注。
- M034证实存储、审核、有限修改链可运行；仍有角色表达、事实语义、上下文与延迟缺口。工程约束通过不足以证明人物表现。

## 初步一手研究映射

本轮核对了论文摘要/作者项目说明，以及Generative Agents指定规划源码；未完成全文系统比较、复现、依赖评估或选型。下列均为候选机制，不是决定照搬的架构。

| 工作与一手来源 | 已核内容 | 对本项目的借鉴问题与限制 |
| --- | --- | --- |
| [RoleLLM](https://arxiv.org/abs/2310.00746)、[作者仓库](https://github.com/InteractiveNLP-Team/RoleLLM-public) | 将人物档案、角色知识提取、说话风格模仿及角色条件训练分开 | 材料事实与表达倾向应分别形成并验证；当前公开仓库入口主要是说明/资料，不当作已经可直接复用的完整实现。是否需要训练另论 |
| [CoSER](https://arxiv.org/abs/2502.09082) | 组织真实文学对话、情境、人物经历和内在想法，并以给定情境的角色模拟训练/评价 | 人物理解不能只有脱离情境的形容词；应保留“在什么情境，对谁，为什么这样说”。论文数据标签与角色模拟不自动成为我们运行时真实状态 |
| [Generative Agents论文](https://arxiv.org/abs/2304.03442)、[规划源码](https://raw.githubusercontent.com/joonspk-research/generative_agents/main/reverie/backend_server/persona/cognitive_modules/plan.py) | 记忆检索、反思与计划参与行为；源码`revise_identity`/`_long_term_planning`把近期记忆联系到状态和日程 | 可研究自己的关注如何持续影响行为；其模拟日程和自由生成状态不能直接当作本项目已发生事实，也不据此启用自动人格重写 |
| [InCharacter](https://arxiv.org/abs/2310.17976)、[官方实现](https://github.com/Neph0s/InCharacter) | 用访谈式评估考察人物人格表现，超出知识/词句相似度 | 应测多情境下的反应和选择；人格量表与模型评委只作辅助，不证明主体有心理或替代用户体验 |
| [EmoCharacter](https://aclanthology.org/2025.naacl-long.316/) | 单/多轮情绪忠实度评估；其实验中通用能力增强不必然改善角色表现，真实对话数据有帮助 | 事实检查不能覆盖情绪反应与人物感觉；“换更强模型”或加描述不是未经验证的充分方案 |

## 本轮采取的方向

先围绕一个可复用的小结果研究：系统从受控材料提出有来源、适用情境和不确定性的人物理解候选，实际用于未见对话；在梅莫莉和一个轻量对照角色上检查是否可重复。对照是检验通用性，不等于立即交付多人物平台。

执行顺序：具体失败→对应能力缺口→核现有实现→查论文与源码的具体机制→选最小适配→在角色互动中比较效果、成本及失败。关注范围先放在材料理解与解释如何影响表达；状态/目标/主动性按已证依赖再接，避免一次扩建整套框架。

复用证据、Facade/ModelGateway、单Timeline和原子发表；材料接入与游戏呈现归产品。Codex负责实现、查证和对照，系统负责可重复的语义流程，用户判断人物体验。角色理解候选不自动改写封存定义，新模型材料/用途按准确对象处理。

当前是方向与初步研究准备，无新增角色模型调用、用户数据动作或安装；原M034失败保持，既有接口/隔离试聊工作不作为已完成体验报告。
