# M031：自然经历的本地保存与接续

2026-10-30，承接[M030](memorie-natural-experience-m030.md)的真实失败和产品用户“那就继续”。本轮交付隔离实现、验证与提交，不把它称为游戏体验完成。

可观察结果：普通文字形成一段有期限的原话；纠正后，后续问题引用新理解；关掉再打开同一身份仍可接续；停用或到期后不再使用。模型选择和表达在本轮均为明确的本地合成提议，真实模型能否判断正确、是否像人物尚未验证。

复用 ApplicationFacade / production composition、LocalIdentityAuthority、LOCAL living schema6、SharedActivityRecord、同一 RuntimeTimeline 与 Publication。新增可选 natural 字段；旧记录不写 None 字段，保持旧序列化。没有第二份人物记忆文件。最终发表重新从当前用户原话、受信接收时间、模型选择和当前来源构造结果；模型不能改写引文或单独提交记忆。新 LOCAL 资格只接受未服务的新身份或自身重开；现有身份不自动转为新用途，远程 Gateway 在访问身份前拒绝。

M030证明“增加禁令”仍不能阻止开放回复编造新活动。此次采用有限表达试验：模型只选提问、意愿、引用用户原话、引用已提交文字方案、承认不知道、回应纠正等动作和已知来源编号，Python生成正文。只有有效原话或确实提交的文字方案能进入相应句子；文字方案不冒充采药、浇水等真实世界活动。原话引号做显示转义，canonical 原文不改。

这是本地事实边界试验，**固定句式不是人物最终对话方案**，不能据此证明人格、主动性、自由交流、复杂经历理解或自然程度。下一步应验证真实模型的选择与表达方式，并在来源可核验的前提下恢复足够自然的表达空间；新远程输出协议须准备准确用途。现有原作资料和研究依据沿用M030，本次为工程接线，没有引入新的心理机制。

验证结果：11项新行为通过，覆盖纠正/同身份重开/停用、模拟跨日只读过滤及下一回复、回复失败时不半写入、准备前/后的中断恢复、已提交方案引用与依赖失效、远程拒绝、旧身份不转换、伪造来源在最终发表时拒绝、披露控制及引号边界。既有裁决及共享/生活/整体接续兼容通过；此前组合运行中测试代码未关闭SQLite连接触发警告，已修复并重验相关项。故障注入为合成，不声称真实断电或真实跨日。

边界：本轮没有新增真实模型请求，没有读取/复制活跃用户Timeline，没有升级用户数据、切换生产底座或安装游戏DLL。历史M030/R2的失败仍保留，不能被工程通过覆盖。
