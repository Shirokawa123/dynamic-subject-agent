# S105有限真实验收

仅在合成行为验证与独立复核接纳后执行。独立自动验收分支显式绑定development_run=True；模型调用包含聊天两阶段，统一计入同一开发24上限、日6决策/2分享及总200。开工实查67已用/133余，执行前再读共享账本。真实故障即停止该次验收，不隐藏首个结果或盲重试。

建议一轮约8次调用：

1. 合成初识消息建立一次真实committed用户交流（最多2次）。
2. 开启生活、保持分享关闭，显式模拟推进一次形成文字方案（最多1次）。重复同请求验证不再调用。
3. 开启应用内分享，发authenticated heartbeat建立租约；仅根据已经提交的事件考虑一次分享（最多1次）。模型可选择不分享，保留原结果，不换题刷成功。
4. 继续两次明确模拟推进，核对版本实质变化和保留/重做/暂缓（最多2次）；若已暂缓或完成，不强行凑三步。HB在未回复/已considered同事件时不得重复调用。
5. 关闭重开，合成追问该项目发生的变化（最多2次），检查与已提交记录一致。随后关闭历史/暂停/分享关闭及查询恢复用本地接口验证，不额外生成。

所有实际用户文本均为助手专门编写的合成测试输入，不读取用户正式聊天。只读/控制/重放/暂停检查必须零Provider。文字方案和对话保留在该分支canonical Timeline，不另存prompt或完整历史副本；开发报告记有限合成观察、故障与调用元数据，不复制私人聊天。

只在上述闭环成立后创建供用户体验的独立生活分支，development_run=False，仍受日6/2和同一总200，不把24误当用户终身额度。该分支初始暂停、分享关闭、聊天为空；原8766聊天版本继续保留。默认客户端保持可见窗口在线才续租，后台系统通知/离线补算不启用。
