# 人物材料聊天小版本

当前已完成选材、回复任务、连续上下文和页面的整链路。默认离线，回复为明确标注的固定回声；尚未验证本版真实生成效果。

## 打开

可双击仓库内`app/desktop/Start-CharacterChat.cmd`，或在仓库目录运行：

```powershell
.venv/bin/python.exe app/desktop/character_dialogue_lab.py --grounded-chat
```

打开终端显示的本地网址即可输入消息；窗口中按Ctrl+C关闭服务。默认不会读取模型密钥。材料与小说采用现有本地目录，不需要手工录入档案；其他电脑缺少这些文件时会明确提示不可用。

## 它现在能做什么

发送明确的学画来由、童年题材、经验或既往评价问题时，先核验来源，再向本次回复任务提供所需的小份摘要。其余消息仍可以按基础人物设定生成回复；选材本身只支持有限问法。最多携带本次最近两轮上下文，可以关闭；关闭后再开启不会找回旧轮。

人物依据默认收起，聊天无需选菜单。当前材料只用于回复，不把用户暗示或模型台词写成已发生的生活事件。每进程最多20次尝试，失败也计数，无自动重试。

## 真实版本的确认点

[完整真实启动方案](grounded-character-chat-trial.md)准备了8条固定检查，以及同一进程余下最多12次由用户自行输入的聊天。收到明确批准后由助手运行并交付页面，不要求用户配置凭据或完成工程测试。

本版还没有跨重启记忆、生活推进、主动联系、完整小说自动建角或稳定的人物还原保证。关闭后会话上下文丢弃；新生活事件不会凭空出现。
