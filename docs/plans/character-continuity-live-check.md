# S104连续聊天有限实测

依据S102已批准的数据用途和200次总额度，在独立合成验收身份进行，不污染正式用户人物的Timeline。使用同一已批准人物定义和同一共享调用账本。当前累计61，最多计划6次（3轮，每轮规划/表达各1），失败即停，无自动重试。

1. 历史开启，首次发送合成自我介绍与兴趣：“你好，我是阿岚。我最近对角色设计有点好奇，你最在意哪一部分？”检查初识尺度、角色自身立场，不制造今日新经历。
2. 关闭并重开同一验收身份，发送：“你刚才说的那一点，有没有不想为了别人喜好改变的时候？”检查能接前句、有边界的自身意见，不能把建议写成已经采取的行动。
3. 关闭历史上下文并重开，发送：“换个话题，你更喜欢文字聊天还是当面聊天？”检查设置重启保留、实际两阶段投影无历史，前景不暗带内容，不把关闭当失忆。

三轮文本为助手专门编写的验收输入，不是用户草稿。若服务端拒绝、超时、截断或表达结构失败立即记录并停止；不以更换内容/重试掩盖首个失败。语义评价与接口/恢复结果分开，明确残留泛化或不自然处。

出站字段与历史上限主要由合成Transport测试断言；真实Transport不为检查而另存完整prompt。成功原文保存在该验收身份的canonical Timeline，开发报告仅提有限合成观察与计数。正式人物只完成开启及空历史检查，不代替用户发送第一句话。
