# 角色聊天的拟议结构与已有基础

2026-09-20。助手解释草案，回应“需要多少小说、怎么实现、已有多少基础”。不是已定架构或实施授权；当前不修改生产代码、导入小说或新增Provider调用。用户决定以[方向记录](character-chat-direction.md)为准。

## 多卷资料与角色起点分开

资料库可以覆盖同版本多卷/全套，角色仍从选定的开篇阶段出发。较完整的资料便于交叉核对，但不能保证自动还原准确，也不是首份演示必须等齐全套的条件。第一卷与重点片段可以先工作，缺口应标明。

拟为候选区分来源卷章/段落、叙述位置、事件发生时间、角色知情时间、性格或关系的适用阶段，以及证据/推断状态。后卷可能说明早已发生的背景，也可能描写成长后的性格；两者不能一并塞进开篇角色。来源顺序和时间语义的区别已在[EPUB研究](../research/2026-09-20-novel-source-boundary.md)核实，具体语义识别方案仍需素材和原型验证。

## 拟议流程

1. **本地小说资料整理**：按卷章读取、保留版本指纹及来源位置；建立可重建的索引，原文不进入代码仓库。不能把全套直接视作一次模型提示。
2. **有依据的人物候选**：分段分析并跨段归并姓名/关系/经历/表达示例，保留冲突与不确定性。先做来源可追溯的建角与检索方案，不默认训练或微调模型。
3. **起点人物设定**：从材料中选出起点适用的背景、知识、关系和表达特征，用户简明确认。资料层知道的内容不等于角色可用内容；后期语气也不能无条件影响开篇人物。
4. **虚构生活与事件**：根据当前状态和既有事件提出日常发展，经一致性/权限等可检查条件校验后记录。先有可接续的虚构事件，再据此产生情绪和分享动机；不把聊天临时编造的“昨天做了什么”倒当既成经历。
5. **自然聊天与主动分享**：组合当前对话、可用人物信息、共同经历及当前状态，形成自然消息；主动联系服从已有频率/未回复边界。小说资料、角色自己的经历与用户说过的事情区分归属。

正式运行仍保留单一canonical Timeline与唯一写入者。小说原文是来源资产，检索索引是可重建投影，不能引入第二套可独立改写同一运行事实的存储。原型可以用明确标记的临时时间和预设情景探索体验，不能据此宣称真实生活引擎或全文分析完成。

## 当前代码已具备什么

| 已有基础 | 能复用什么 | 不代表什么 |
| --- | --- | --- |
| TextSourceCharacterAuthoring | 纯文本候选提取、逐字证据核对、用户确认；当前单份上限16000字符 | 没有多卷EPUB解析、完整人物归并和剧情时间推理 |
| Source Draft / Freeze Mapping / LocalIdentityAuthority | 草稿、设定预览、封存、身份切换与重启隔离 | 不能直接把全套小说变成可信人物 |
| Memory / Knowledge / Timeline | 持续对话、记忆/知识检索、原子提交与恢复 | 用户记忆不等于角色自己的世界经历，现有窗口也不是全文资料检索方案 |
| Relationship / Situated / Medium | 已有关系立场及短中期状态的裁决和保存路径 | 不是完整的角色心理、人物成长或自主生活引擎 |
| ModelGateway / Credential / ApplicationFacade | 模型调用、凭据管理和产品业务入口 | 既有投影授权不覆盖新的全文分析或生活生成用途 |
| Windows页面与本地任务effect | 可启动、可持久运行的产品外壳与提交/恢复经验 | 当前页面和任务流程并非目标聊天体验，仍须重新组织主界面与聊天编排 |

代码核对：[文本建角](../../src/dynamic_subject_agent/source_character_authoring.py)、[身份权威](../../src/dynamic_subject_agent/local_identity_authority.py)、[生产装配](../../src/dynamic_subject_agent/local_product.py)。运行契约见ARCHITECTURE；本表只描述已查到的接缝，不承诺旧代码原样适配。

## 先验证什么

先用有依据的小份起点人物资料完成已确认五情景演示，检验人物感、连续性、自然交流；材料收集可以更全，处理先聚焦相关片段。随后再确定跨卷提取与生活事件模块的实现方案。机械校验能发现引用、时间和状态冲突，不能证明语气一定像原作；人物还原仍需用户反馈。

还未定：实际文件与版本、跨卷语义冲突裁决、具体生活机制、原型哪些部分使用真实生成，以及外发内容/目的地/调用预算。收到文件后可先本地核对；模型分析需落实具体方案，不能沿用原16000字符用途直接扩成全套外发。
