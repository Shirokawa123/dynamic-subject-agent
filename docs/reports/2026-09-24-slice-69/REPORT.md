# Slice-69：连续语境与人物自我知识核对

用户结果：人物知识整理可以从引用回到真实相邻语境，减少孤立句子导致的归属、时间和披露误判。本片交付作者侧本地检查能力及一版补强草稿，尚未改变聊天回复。

## 实现与复用

同一 ApplicationFacade 的人物预览接受 CharacterContextRequest；从已核验文档快照取相邻完整段落或文本节点。默认前后各5项，各侧最多20项、合计最多6000字符；超限明确拒绝，不截断句子，不跨文档拼接或替相邻文字推定说话者。CLI新增 --context / --before / --after。来源缺失、损坏与请求错误保留不同结果。

复用仓库已有EPUB解析、文件/文档/引文指纹与隔离预览装配，没有第二文本库、运行写入或新依赖。继续采用[既有官方规范研究](../../research/2026-09-22-character-evidence-model.md)的来源派生和时间限定机制；本片核对其适用性：位置及完整性可由代码验证，语义、人物知情和披露不能由位置自动推出。未引入第三方代码，无新增许可证或服务边界。

## 实际材料核对

通过实际Facade读取9个连续窗口，涵盖五卷中的6个文档，163个位置记录去重后159个位置；这是定向审核，不是五卷全文分析。原文及细粒度笔记仅本地保留，新增原文未发送Provider。

- 家庭：开篇同住成员不等于完整照料关系；跨卷补强监护人的身份及关系。未追加法律权限、确切接任日期或全部监护条款。
- 工作：补入职业起步的评奖、获奖与工作联系；未补造具体奖项、参赛年龄。母亲参与洽谈的指称与本人知情仍保留待核，未直接写入她的起点自我知识。
- 约定：区分哥哥与姑姑的条件、妹妹自己的工作约定、编辑谈到的保密条件。妹妹自己的约定时间/内容未明确，不能套用哥哥的条款。
- 动机：补入过去希望画得更好、更多并被更多人看到的创作愿望；不将过去愿望变为当天任务或永久目标。
- 披露：原作确有否认笔名后撤回的情境。修正此前过宽诊断：单句否认不足以证明本人知识缺失。旧聊天输入确实缺少职业背景，但后续验收必须同时检查内部知识、披露理由和连续反应，不能以禁止“不知道”台词代替修复。

独立助手复核指出覆盖元数据仍沿用三卷，已纠正。审核不是用户或人类专家审核。复核认为母亲知情可作合理推断，主审核仍将该项保留为编辑视角，等待指称和获知旁证；不将这一分歧隐藏为确定事实。

最终本地草稿 v6 共35条命题，24条可纳入提议起点、11条排除或待核，九维均partial。此计数衡量整理结果，不是人物完整度或自动提取准确率。提议起点仍不是新封存的正式人物。
