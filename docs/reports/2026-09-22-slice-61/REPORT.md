# Slice-61：普通消息触发本地材料预览

2026-09-22，基线ec06355。离线lab发送普通消息后可自动显示本地选材结果，不必先选话题。仅实现有限中文明确问法，不是通用意图理解；材料仍未进入模型回复。真实Provider调用0，凭据读取0，R2投影/digest未改变。

## 实现

复用ApplicationFacade.preview_conversation_basis与S60完整性/时间/初识策略，增加typed BasisMessageRequest。完整消息≤1000字符，NFKC/空白规范化后整句匹配学画来由、童年题材、年限、既往评价等有限问法。问老师只选学画来由，问童年画什么只选题材；不会因为同属一个话题就披露该话题所有材料。

引用、转述、否定、复合追问、模糊指代和声称亲密不匹配时返回no-op/message-not-matched，且不读取源文件；这不表示全库无相关资料。匹配后继续完整核验，缺文件与校验失败不伪报为空。原有显式话题预览保留为检查入口，没有新增关系升级参数或历史读取。

页面只在显式启用材料预览的离线模式下，在成功发送后请求本地预览；预览与发送独立，失败不重发聊天。序列号阻止旧响应覆盖新预览，显示结果对应的消息/手动话题。CLI新增--preview-message，与真实批准/suite互斥。HTTP只接受topic或message的单一请求结构，不接受trusted等分享覆盖字段。

## 复用与取舍

功能缺口是S60仍需手动选话题。复用既有整句闭集处理思路而非无约束关键词检索；不直接套用recent_dialogue的所有控制词，因为它针对历史外发，含“最初”等词会与正常学画问题冲突。本片采用完整问法匹配，宁可返回未匹配，也不根据局部词汇披露往事。

成熟设计沿用[先前架构研究](../../plans/character-chat-architecture-alignment.md)中对[Generative Agents原论文](https://arxiv.org/html/2304.03442v2)来源/经历与回复分责的结论；检索相关不等于知情或愿意分享。没有引入其框架、打分器或Reflection，也无新依赖。该有限路线能检验真实消息到选材的衔接，但覆盖面小；更宽泛语义理解仍未实现，不能靠不断列同义句宣布自然聊天完成。

## 使用与剩余工作

```powershell
.venv/bin/python.exe app/desktop/character_dialogue_lab.py --basis-preview
.venv/bin/python.exe app/desktop/character_dialogue_lab.py --preview-message "你画画多久了？"
```

页面仍显示固定测试回声，不能当真实人物体验。当前没有把选材送进回复，更没有解决模型对个人经历的扩展；后续需定义有界材料到回复的接入方式和具体外发范围，保留时间/分享限制，再实际评价生成质量。
