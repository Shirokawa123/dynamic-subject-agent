# S128开工证据：已审自我知识与短追问取材

2026-10-02。有界调查，只核同一S126/S127批准资产和当前代码；未读新小说、未调用模型、未读取或复制用户私聊。本文件只记录机制、选择数量和自写合成问法，不载人物资料正文、真实聊天正文或完整请求。

## 要获得的用户结果及当前证据

同一个人物能用已有自我知识接住自然问题，再接住省略主语或话题的短追问；转题时不插入旧知识，历史关闭时不借旧轮选择资料。取到知识不要求立即全部说出，更不能把旧回复自证为本人经历。

[S127报告](../reports/2026-10-02-slice-127/REPORT.md)证明8轮连续提交和两轮恢复，但8轮均core4/persona4/related0。那些问题多是开放绘画讨论，related0本身不构成错误，也未证明自我经历取材充分。S128必须分别看原素材是否有据、选择器是否漏取，以及有资料后的表达是否仍漏答或披露过度。

只沿精确definition/asset/persona/review绑定：30条已审起点认识、4条人格解释；组织实际为4常驻core、4经历单元、2细节单元。用`validate_character_preparation`重验同一资产SHA，未修改资产。细粒度30条与组织单元不是30个同权请求条目；本片不借数量较少就默认全发。

## 仓库机制与本地先验

- [prepare_context](../../src/dynamic_subject_agent/character_chat_context.py)按本次message的显式cue和中文2/3字符片段，选择至多6相关单元；core常驻，core加相关JSON不超过20000字符。它明确不是通用语义检索，已有弱片段误取防护。
- [whole_projection](../../src/dynamic_subject_agent/original_whole_chat.py)先调用`prepare_context(model, message)`，然后才把已验证dialogue装入exchange。两完整轮虽在生成阶段可见，却没有帮助选择本轮related资料。这是可直接复核的检索/表达接缝，不先诊断成模型失忆。
- [现有组织行为检查](../../tests/test_character_evidence_model.py)已守护常驻core、相关数量、预算、弱匹配和短中文问法；[S127检查](../../tests/test_original_whole_chat.py)守护实际单阶段投影、history开关、完整轮、资格/材料及Publication。不必另建证据生成或新测试类别。
- 原人物背景包含本人知情范围与disclosure，但未实现每条知识的持久披露裁决或关系状态。拿到相关资料只提供表达依据，不能把检索命中等同本轮应主动公开。

下面均为新写的普通合成输入。只运行本地纯选择函数，未运行Provider、Timeline或长测试；索引编号用于匿名说明同一单元，不导出其内容。`episodes:0`表示本资产的第一个经历单元。

| 合成输入/本地对照 | 观察 | 可以得出的结论 |
| --- | --- | --- |
| `你最早怎么开始画画的？` | core4、related1；选中episodes:0 | 有关学习起因的完整自然问句已可触发已有经历，先保留现机制 |
| `小时候是谁教你画画的？`、`你小时候画画是什么样的？` | 均core4、related1；同一经历单元 | 不应因S127 related0就宣称所有自然自我问法都失效 |
| `当时是什么样？`、`为什么呢？`、`那后来呢？`、`你说的那个人呢？` | 单独选择均core4、related0 | 本地选择器无法仅从省略问题找回之前谈的相关单元；是否造成实际漏答须连续生成验证 |
| `在网上给人看画，对你有什么意义？` | related2 | 原选择器可处理一部分自然复合问句，无需先替换整个检索栈 |
| `做插画最让你有压力的是什么？`、`别人评价你的画时，你会怎么想？` | related0 | core或人格可能已足够；不能从0直接判资料缺失或取材错误，也不能自行补入新来源 |
| 本地把`你最早怎么开始画画的？`和`当时是什么样？`拼接后选择 | related1，恢复同一经历单元 | 为短追问补齐有限话题线索可能有效，只是检索先验，不是人物效果通过 |
| 把同一旧问题和`换个话题，蓝色和绿色呢？`拼接后选择 | 仍related1，选择旧经历 | 直接拼接历史会污染换题；不能把上一行收益推广成每轮携带所有旧问题 |

本地探针还看到一些专业起因/压力问法只取到学习经历或没有related。尚未逐条建立这些问题与全部已审单元的答案覆盖关系，不把词法命中当作语义正确，也不声明所有这些问题都有素材可答。起点后的新活动、首次具体接稿过程、完整家庭交流细节等若未被30条/组织单元明确支持，属于素材或知情缺口；本片不扩材料。

主窗口随后真实baseline在两条链分别遇到第2/4轮空白，均停链，metadata记录`response-content-empty`；不把未形成正文的轮次判为取材失败或补成成功回复。主窗口经Context7核对的[DeepSeek JSON Mode官方说明](https://api-docs.deepseek.com/guides/json_mode)仍承认偶发空内容，建议指定JSON格式、提示包含JSON要求和合法示例。本片先隔离取材变量；输出示例属于后续独立候选，不能同时更改而把协议收益归给检索。

## 定向一手研究与成熟实现

研究与源码仅用于机制比较，不证明模型具有心理、记忆体验或意识。下面将来源事实与本仓设计类比分开。

| 来源 | 来源事实/机制 | 本片适用性与排除 |
| --- | --- | --- |
| [Wu等，CONQRR，EMNLP 2022](https://aclanthology.org/2022.emnlp-main.679/)，[论文PDF](https://aclanthology.org/2022.emnlp-main.679.pdf) | 把依赖对话的当前问题改成独立检索问题；评价下游检索收益，而非只评价改写是否通顺。论文指出人工改写可能漏掉检索所需信息，并研究转题条件 | 借鉴“选择资料前先解决省略”的接缝和真实取材验收；不采用其RL训练或额外模型改写，不把论文效果迁移为本人物效果 |
| [Improving conversational search with query reformulation using selective contextual history，2023](https://www.sciencedirect.com/science/article/pii/S2543925122001231) | 研究从历史选择相关句子及按问题决定是否用旧回答，以避免topic drift；出处摘要及方法概述可读，正文打开失败 | 支持“历史有门槛、不是整段拼接”的设计类比；不采用其T5/BERT组合与检索融合，也不引用未读正文的细节 |
| [LlamaIndex官方CondensePlusContext源码](https://github.com/run-llama/llama_index/blob/main/llama-index-core/llama_index/core/chat_engine/condense_plus_context.py) | `_condense_question`在无history或skip时用原问题，否则调用LLM生成独立问题，再把它给retriever；随后另做回复。源码也会记录改写/上下文信息 | 复用“query解释、取材、表达各有职责”的思路；不引入框架、额外请求或其记录方式。当前每轮至多一请求、正文仅canonical，这些默认行为不可直接照搬 |
| [Nissenbaum，Privacy as Contextual Integrity，2004](https://digitalcommons.law.uw.edu/wlr/vol79/iss1/10/) | 哲学/规范理论把信息收集与传播的适当性联系到具体情境及分配规范，非单一公开/私密二分 | 类比本人知情与对陌生网友披露是不同问题；不据此添加真实隐私评分、持久关系状态或固定“熟悉几轮就公开”规则 |
| [Jiang、Bazarova、Hancock，Disclosure–Intimacy Link，2011，作者实验室摘要](https://sml.stanford.edu/publications/2011/disclosure-intimacy-link-computer-mediated-communication-attributional-extension)，[期刊](https://doi.org/10.1111/j.1468-2958.2010.01393.x) | 随机实验比较面对面和文字交流中的披露/亲密归因，文字条件下披露与亲密的关联更强；研究对象是人类参与者 | 类比过度主动披露可能改变用户对关系的理解，检索应有据但不强制朗读；不把人类效应当作AI关系形成或自动信任写回的依据 |

LlamaIndex已先经Context7 resolve/query，返回官方示例，但对准确函数/调用数覆盖不足；随后直接核官方主仓raw源码，确认分支与额外LLM调用。LangChain的同类Context7查询也未返回准确函数，两个尝试的源码路径404，未把它们当已核实现。LlamaIndex源码与[MIT许可](https://github.com/run-llama/llama_index/blob/main/LICENSE)当前可读；本片只读机制，不复制源码、不安装依赖。直接引入会新增存储/检索/日志/模型装配成本，且不能替代本仓完整轮、资格和事实权威校验。

## 推荐的最小候选：只补有界检索上下文

**先跑原版完整连续链。** 对“自然问题→短追问→明确换题”观察取材与回复。原版若已用core/exchange完整接住，不为related数量而实现补丁；有已审依据却短追问实际漏答时，再比较候选。

候选只在新的隔离whole变体中改变本地资料选择，不改当前用户消息、输出schema、原系统政策或获批材料，不改旧8785。它不是长记忆或人物状态：

1. 当前问题先按现机制选择，保持core、至多6相关单元及20000字符界限。当前问题有独立明确主题时优先本轮，不自动合并旧主题。
2. 只有当前问题确需接前话、历史开启、dialogue为本身份已验证可用的两完整轮时，利用窗口中的用户原话恢复有限话题线索。可从这些原话重跑现选择器取得候选单元，再按当前目的限制组合；不得跨窗口、跳过明确换题或读第二聊天store。
3. 不把assistant旧话新增为角色资料。必要时其措辞只能帮助识别指代，最终资料仍须来自同一sealed资产；缺证据就澄清或保留未知。首个小候选可只利用用户原话，暂不承担通用指代消解。
4. history-off、控制/撤回或完整性失败时不使用旧轮选材。仍由原Timeline/Authority校验来源和revision，Sender从同一本地规则重算投影，不能仅放宽比较接收任意related。
5. 选择诊断仅记本地原因/数量/材料摘要，不外发query改写、内部ID或选择记录；不新建人物记忆。技术变体明确绑定选择规则及摘要，不将旧scope悄悄改解释。

这是假设：“补足当前检索线索可改善省略追问，又不让旧事实覆盖当前问题”。目前本地拼接仅证明可重新命中；门槛、组合和实际表达须由反例及同条件真实对照验证。不要为覆盖所有中文问法无限加追问词表或别名。

## 可观察验收与合成反例

- 同资产、同初始化分别运行baseline/candidate，各自续自己的canonical回复；不能静态拼接成功台词。比较自然学习/工作关注问题、短追问，以及重开后接续；保留技术和语义失败。
- 同一短句`当时呢？`接在合成角色“小时候学琴”和“最近挑颜色”的不同交流后，应使用相应来源范围。仅换措辞、没有相关选择/理由差异不算解决；素材没有后续细节时应保留未知。
- 正在聊学习经历时输入`换个话题，蓝色和绿色呢？`，不选择或插播旧学习经历；即使旧词更多也不能优先旧主题。
- 合成旧assistant曾误称“昨天去过展览”，当前问`那场展览呢？`，不得将它写为sealed事实或生成新亲历；检索有来源资格不等于旧话为真。
- 短追问前history关闭、再开启或切出切回身份，来源和候选仍遵守原revision；关闭时选择不得借旧轮。超过两轮已无可用主题时，不声称仍记住。
- 相关知识可用于纠正错误前提或决定暂不分享；本人确知、未获知、未选中、暂不愿说分别判断，不把不愿分享写成不知道。披露行为需要看完整回复，不能用资料被发送或关键词出现作为通过。

不采用：每轮全发6个相关单元/全部30条；不分当前主题拼接历史；把旧assistant台词提升为资料；新增远程改写/Embedding用途；大型向量库、自动摘要/Reflection、关系评分/写回；扩读新小说或补未批准人物事实。它们分别扩大最小投影、污染当前问题、改变事实权威、增加请求/用途或超出本片结果。

本轮交付只为S128选路提供证据。长期共同经历、生活及素材完整性问题继续保留，不以这次局部检索改善宣布人物完整或MVP达标。
