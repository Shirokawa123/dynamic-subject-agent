# 连贯人物背景的组织方式

Slice-70，2026-09-24。已证实缺口：少量话题命中才提供人物材料，核心身份与职业经历会缺席；当前起点预览虽保留依据，但平铺条目尚未构成可读的关联认识。

核对[SillyTavern官方Character Design文档](https://docs.sillytavern.app/usage/core-concepts/characterdesign/)：角色描述、人格摘要和场景是持续上下文，示例对话则可能随上下文预算被移除。可借鉴的重要机制是让关键背景持续可用，并把人物背景与对话场景分别组织；不能依赖示例台词承担基础事实。

本项目取舍：先以同一份已核验的起点视图组织稳定核心、相关经历与关系、起点处境以及未知边界。原作背景和新增社交场景分开，材料不足不通过人格标签补齐。具体常驻预算及细节选择要到F5按真实行为验证，当前档案不直接成为Provider输入。

继续复用[来源和时间表示研究](2026-09-22-character-evidence-model.md)。SillyTavern的字段组织不能自动解决人物知情、未来倒灌或来源真实性；本仓库保留Facade审核/时间过滤，不导入外部角色卡覆盖权威来源。本片仅借鉴公开设计，无代码复制、新依赖或外部服务接入；因此未产生软件许可证集成问题。
