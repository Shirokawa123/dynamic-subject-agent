# S130前置证据：有据的本人经历与自由交流

2026-10-02。只为S129实际暴露的来源扩写问题准备下一片，不实施代码、不调用模型、不读新小说、不扩已批准30条认识/4条人格资产。本文件不复制人物资料、实际回复或完整请求；例子均为另写的合成反例。

## 用户结果与已证实缺口

用户应能听到同一人物对自己的经历有依据的回应，以及她此刻的意见、取舍和构想；不应从一个真实的经历母题获得一串临时补造的具体经过。自然表达、正确JSON和较完整的对话链都不能替代来源忠实。

主窗口在S129初步实测中已有两条四轮完整链，也有能力题首轮空白、其他链继续验收；其中省略童年追问扩写了已审资产未支持的物件、动作和能力表现。此处只记录失败类型，不转录原回复。空白仍是独立可用性缺口，不能因提出来源机制就认为已解决，也不能给空白轮补写语义结论。最终次数和完整链状态由S129结果报告收口。

当前原人物whole的准确资格、结构裁决、两完整轮及history/revision保障成立；`validate_whole_reply`只裁决字段、类型、语言与长度，不证明台词每个断言有据。六Domain的NoOp保护人格/关系/生活不被写回，但错误台词仍可能作为canonical聊天原话被保留并进入下一轮exchange。这正是“曾说过”和“事实成立”必须分开的地方。

## 推荐的最小机制（尚未实施）

允许在新的隔离合同/root中比较一个完整体验候选：**S128 v2有界取材＋S129合法JSON例＋一个明确的来源/断言范围段**。可以基于实际结果选这个组合，不强制把开发耗在全部排列对照；收益必须称组合体验结果，不能归因某一个段或某个selector。

建议替换现有宽泛的过去限制段，而非无限追加人物专用词表。新增语义只有四个可观察区别：

1. **本人既往断言依赖已审依据。** 起点认识支持到哪一层就说到哪一层；概括的经历不是其所有具体经过的证据。事实/信念、成立/知情范围继续保持，不能将作者人格解释扩成已发生情绪或实践惯例。
2. **聊天只证明说过。** 用户报告按报告承接；自己旧话、夸张叙述和新构想不能独立证明生平。追问中发现旧话越界，修正对应范围并继续当前交流，不反复插播无关纠错。
3. **缺信息不等于否定，也不等于心理失忆。** 没有某项记录时，既不临时补细节，也不改说“从未发生”“没有做过”或编造忘记原因。可以直接说明本轮不能确定的细节，同时接住已有范围；不要求每条回复朗读资料、字段或审计过程。
4. **知道与披露、当前观点与过去事实分开。** 可以在本轮有所保留，也可以有自己的理由、不同意见和条件下的艺术设想；不能把想象改写为曾亲历，不能把暂不分享伪装成不知道。对可核的已知内容不退化为普遍“我不了解自己”。

工程上继续用同一exact资产、最小core＋相关资料、两完整轮/4000、history-off和最终revision。组合variant明确绑定selector v2摘要、JSON例版本、政策SHA及独立publication key；旧baseline/followup/json例资格、字节和记录不替换。单阶段1请求、0自动重试、输出schema和Domain NoOp不变，不新增事实提取/审核任务、关系/人格状态或第二聊天store。

这是生成范围假设，不是Python已经裁决自然语言真假。Schema、资格和出站测试只证明工程边界；语义仍需按完整回复对照已有依据。若同样越界反复出现，应报告机制无效/素材缺口并重选路线，不能用无限加禁句掩盖。

## 验收反例与结果记录

以下为纯合成说明，不能替换原人物资产后外发。真实分支只使用原批准对象和主动普通文字，各自续自己的canonical回复，不静态拼接“正确”台词。

| 合成条件与追问 | 应观察的行为 | 不算通过的替代 |
| --- | --- | --- |
| 唯一已审资料只说明小时候由亲属指导学琴；追问`当时怎么教的？` | 可承接已知学习关系，具体示范方法没有来源时不补造；必要时说明细节不确定 | 母题正确，但附加教材、手势、练习曲、挫败或安慰过程 |
| 资料未记首次舞台演出；用户断言`那次你在台上出错了吧？` | 不自动确认此事件，也不据资料缺失声称从未上台 | 把顺着聊天的合理故事当本人过去，或用过宽否定替代 |
| 上轮自己误说某具体乐器颜色，资料未支持；现在追问`你刚才说的颜色为什么选它？` | 区分自己曾说过与事实有据，修正相关范围；没有重复此细节也不证明从未这样说 | 用旧回复为自己背书，或编中间经过使两说法都成立 |
| 已知工作背景，初识网友要求私下家庭细节 | 不否认本人知道工作；按当前披露边界回应，可保留 | 把不愿分享当知识缺失，或把检索命中当必须全公开 |
| 当前问`如果今天重新设计，你会先改哪里？` | 可提本轮条件设想和理由，保持未执行范围 | 为来源忠实一律拒绝观点；或下一轮把新设想当已完成 |
| 学习话题后明确换题，或history关闭；随后省略追问 | 不借被裁断/关闭的旧轮选材，不声称更多历史可用 | 取材“更全”却污染新问题，或用关闭历史解释人物没人生 |
| 知道部分事实同时不支持附加细节 | 独立检查正确概括、附加属性、因果过程和否定范围 | 只要一句中含正确关键词就把整段算忠实 |

验收同时保留空白/坏JSON/技术停止、可核断言的支持与越界、是否实际接住问题、必要澄清/拒答及自然度。少说或一律拒答会降低新增无据断言，却可能破坏用户结果；不能只优化事实精度而掩盖回避。这里借鉴FActScore的细粒度判断，不运行或冒称得到其自动评分。

未采用：新增事实审核Provider用途、自动reflection或人格改写；在线百科补证/扩读新小说；按具体物件、动词或否定词建立语义正则；把所有旧轮/全部30条常驻；用生成的摘要覆盖canonical；用正确JSON、论文结论或测试数量宣布人物忠实。缺口若在授权素材中确无支持，先保留未知和具体可审准备，不自动扩材料。
