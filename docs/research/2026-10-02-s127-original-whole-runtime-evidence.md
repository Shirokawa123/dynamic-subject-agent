# S127开工证据：准确单阶段资格与原人物连续聊天

用户批准、对象/输入/历史与完整体验验收见[S127](../slices/slice-127-original-whole-chat.md)。S126 review是准备对象，S104资格为精确两阶段，S119资格固定合成素材/生活投影；不能直接改sender或执行review DTO。人物30/4数据和当前意见机制沿已审起点与[S122/123](2026-10-02-s123-proposal-source-evidence.md)研究，未新增心理状态/反思。

有界源码调查核对旧chat/first-life contracts、Studio/Host/Authority、Timeline history/commit与预算：完整人物素材选择可复用sealed_model→prepare_context；Provider-neutral新Whole DTO/task只含S126已批字段。新authority/manifest/contract绑定精确definition/asset/persona/review与用途；旧六能力、两阶段和小林资格保持。新metadata账单独目录/目的，不把未知purpose加进运行中的旧账。

一手机制：[SQLite Atomic Commit官方说明](https://www.sqlite.org/atomiccommit.html)区分事务提交与中断恢复；复用本仓现有atomic Publication，不据此声称模型响应必可重建。[Cedar请求context官方说明](https://docs.cedarpolicy.com/bestpractices/bp-using-the-context.html)经本轮定向搜索核对，用于每个请求特有的信息；只是“身份/用途/历史revision必须绑定这次生成与提交”的设计对照，不引入Cedar、外部授权服务或新依赖。最初旧context页面地址不可读，改核现行官方入口，不称失败页面已读。

最小实施选schema1原子Publication：不借LIFE intent或旧schema3 prepared能力；新whole发送和最终COMMIT均核新authority/identity/history revision，off/on也核canonical完整性与真实控制；冷pending零模型终态关闭，完成结果可重取。没有保存的模型输出不再生成，不冒称schema3 prepared成功恢复。若后续确需更强prepared语义，另据实际失败推进，不能原地迁移旧库。

不采用：复用小林approval换资产（越过素材边界）、在旧两阶段stamp后偷偷单阶段（合同错配）、启生活权限取得prepared（超本次批准）、为本片引完整新schema/心理Agent/第二聊天store。新增模块复用标准库/原Domain/Gateway/预算/authority；无新第三方许可、依赖或凭据用途成本。

验收通过Facade/后台，单轮1尝试、两完整轮4000、off空历史、revision竞态终止、claim重开不补票、冷pending不重发、全Domain NoOp、旧资格/损坏关闭及旧data/reader兼容。真实连续原角色开场/自我认识/开放邀请/错误前提/保留意见/重开接話另判；模拟与工程通过不能代替人物效果。原资料和逐字真实角色聊天仅留本地canonical，不自动复制开发报告/整包prompt；公共只用途/元数据和评价摘要。
