# S152 开工证据：frame先于模型补丁

目标/已证缺口/验收见[S152](../slices/slice-152-compact-frame-continuity.md)。复用S150/151的实际界面/typed proposal/Publication/guard，不改既有三段文字plan或建立第二store。

| 已核一手机制 | 适配与界限 |
| --- | --- |
| [Dafny modifies](https://dafny.org/latest/DafnyRef/DafnyRef#sec-modifies-clause) | 可写位置由规格预定，不让操作自己扩frame。借机制，不引入证明器，不把程序frame证明当自然语言理解证明。 |
| [CodeMirror state源码](https://raw.githubusercontent.com/codemirror/state/main/src/state.ts)及[transaction](https://raw.githubusercontent.com/codemirror/state/main/src/transaction.ts) | 独立changeFilter可拒整次或保护区间。模型不得取得跳过filter的字段，违规整批拒而非静默删掉违规则编辑；不引入CodeMirror依赖。 |
| [Hokamp/Liu2017](https://aclanthology.org/P17-1141/) | 指定词句的受约束解码保证词覆盖，不保证命题不变；HTTP无对应hook。保留“光”字不足以排除“没有光”，不采用为主保护。 |
| [LLM-as-Judge原论文](https://arxiv.org/html/2306.05685v4) | 判断有位置/冗长/推理等限制；第二模型提供信号但不是精确修改授权，增加新判断用途/候选投影和延迟，暂不前置。 |

必要调查由只读研究者独立完成，root核仓库与Dafny/CodeMirror一手页面。研究发现、工程类比与待验证假设分别处理；人类grounding/局部修复沿[S150研究](2026-10-11-s150-natural-feedback.md)，本片frame只保证文字范围，不证明角色心理或通用语义。

选择本地窄定位的引号对象替换：在请求前可独立确定字串和具体出现位置；“所有”才允许多处同步，其他字节完全保留。提示不给模型新单位/保护摘要，不额外外发字段；raw生成只3字段，常量/版本从实际任务填入内部DTO。Scoped资格使Python在Provider、Cognition及Publication重新计算同frame，不能只靠一次Adapter过滤。

未采用：同模型输出before/unit_id反向决定可写范围（旧问题改名）；只锁subject/focus（同composition有光线）；关键词保留（可被否定/转移）；整计划本体重构/初始计划重标注（非本次必要，成本与语义标签误判）；二模型verifier（不能替代权限，且新用途）。自然中文所有反馈尚不能独立定位，因此本轮主动限缩自动effect，并说明条件，不以拦截量代替效果。没有外部代码/依赖/许可集成负担。
