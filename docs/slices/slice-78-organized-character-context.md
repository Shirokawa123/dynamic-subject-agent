## 实施前研究结论

复用Slice-74/76研究，并于本片定向搜索和重新打开[ReverieMem](https://arxiv.org/html/2606.25632v1)、[TimeChara](https://aclanthology.org/2024.findings-acl.197/)。前者启发场景经历/视角事实分工及先过滤再检索；后者要求同时测起点可知和不可知，不能用拒答率低替代准确。具体限制沿[机制复核](../research/2026-09-24-character-mechanisms-review.md)：不采用实体/组织自动知情、不引入多专家必调或微调。

人类自我记忆系统的“当前关注唤起经历”可作组织类比，不能证明机器自我或用新解释改写事实。本片只用助手核对的既有资料形成显式核心/经历/细节，保留claim关联，不自动Reflection。

复用现有EvidenceModel、Facade、Gateway与CLI；不建新数据库或引入依赖。先以可解释本地文本线索选择构成基线，中文短词/转述用行为场景检验；它不是通用语义检索。复杂embedding/图服务暂不采用，避免新外发和无收益复杂度。语义改善需后续同预算真实对照，本片准备精确输入及验收。
