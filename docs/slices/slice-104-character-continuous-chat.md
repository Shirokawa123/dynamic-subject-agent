# Slice-104：封存人物的连续聊天

基线5df129e，S103已收口。沿S102已获准整体用途自主接续；唯一执行切片为本片。依据[开工研究](../research/2026-09-26-character-continuous-runtime.md)、[批准范围](../plans/character-continuity-consent.md)、S102本地review-request与S103确认记录。

## 用户结果

打开独立人物聊天，已封存知识和人格真正影响两阶段回复；同一聊天可接续、重启恢复，可关闭近期对话外发。界面呈现真实成功/失败，不把实验candidate或故障当正常已发送角色消息。

## 实施边界

新准确聊天资格和后继QRI/binding沿用S103身份/Timeline；旧dormant与旧六Domain保持各自合同。ApplicationFacade唯一业务入口，open_local_product装配，Authority独占激活与恢复。完整封存资产进入纯投影，ModelGateway两阶段，Python裁决后Publication。严格复用S102数据范围和参数；模型输出不产生世界事实、知识更新、关系进展或长期人格重写。

真实聊天只保存在canonical Timeline，UI历史从其投影。Provider只发当前消息、已授权人物投影、exact runtime identity、最多2完整committed轮/4000字符以及有限前景；无原文引文/证据ID/时间戳/未发送草稿。历史关闭与失败关闭有行为测试；控制配置只存用途偏好，不建立第二chat store。

沿已批准200尝试，起点61使用/139余，计数跨重启保留；无隐式重试，未确定送达照计次。实际验收用隔离synthetic身份，正式用户人物不继承测试聊天。首个backend闭环后补轻量聊天页面/启动器及真实小样本验收，必要时按职责收窄后继切片，不在未获准生活/通知上扩权。

## 验收

- 准确激活、幂等重放、中断恢复；错误来源/basis/资格/registry拒绝，不能旧Provider越权打开。
- 首轮/多轮/重启/关闭历史/超限/失败/幂等，断言实际网关输入和canonical结果。
- 知识人格来自sealed asset，来源文件移走仍能聊，未选中不等于不知道。
- Provider故障不伪造成功；预算跨重启且未决尝试保守计入，无额外prompt/chat落盘。
- 界面后台端点可用，重开显示已提交对话；有限真实合成验收记录效果与问题，不以结构通过冒充人格还原通过。
