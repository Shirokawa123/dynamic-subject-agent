# Slice-53：小说人物五情景独立原型

状态：执行中，root已认领。前置：Slice-52完成方向记录、素材清点、架构评估与正式文档同步；对应[原型评价票](../../.scratch/character-chat-wayfinder/issues/03-five-scene-prototype.md)仍未解决。

## 用户结果

提供一份可直接观看、可选交互的独立演示：选择小说版和泉纱雾/开篇起点→初次相识→隔天生活分享→接续昨天的话题→表达一次不同意见。用户只判断人物感、连续性和交流自然度，不承担工程测试。无需再问Q1–Q17或要求体验旧版。

## 先落实人物依据

仅在用户指定的`.local_sources/eromanga-sensei/`内本地核对原文和已有索引。记录文件指纹、卷章/段落位置及简短事实概述，区分角色起点已知、叙述者信息和未来发展；IF单列。具体开篇段落与必要人物依据未核实前，不凭印象填原作设定，也不把所有人物信息强塞进首次聊天。小说正文及详细本地索引不进Git。

## 原型形式与隔离

- 用prototype技能的行为/状态演示方式回答“生活事件与自然聊天能否连贯”；单份HTML，双击可开、无安装/服务器依赖，靠近桌面页面放置并带prototype名称。
- 位于独立`codex/prototype/`分支和隔离工作区；主线只记录任务、成果指针及反馈，不混入生产页面。
- 所有会话与事件状态仅在页面内存中，刷新重置；不访问正式registry、Timeline、credential或Provider，不调用外部分析模型/生成服务，不发系统通知。
- 预设台词为演示新写内容，不能冒称原作引文；模拟日常为原型新增虚构事件，不能冒称原作事实或真实后台运行。明确说明当前不能自由模型聊天，导入/选择界面不冒充已完成小说自动解析。
- 同时提供五情景引导及可选自由操作，展示相关状态变化。可演示暂停、未回复时不追发、同一分享不重复；临时时钟参数只用于演示，不自行固化产品规则。
- 不做视觉风格大赛、不接入旧生产业务、不开发完整生活引擎。先让用户看到目标体验，再从反馈确定哪些机制应进入正式实现。

## 复用与取舍

复用已确认体验、[架构评估](../plans/character-chat-architecture-alignment.md)及[来源定位研究](../research/2026-09-20-novel-source-boundary.md)；借鉴事件先成立、表达和投递分离、暂停/恢复显式状态的机制。无需引入外部Agent框架或EPUB依赖；原型不用生产存储。真实模型版另有具体用途/投影/预算任务与授权，不能借本原型扩大既有12类或来源提取用途。
